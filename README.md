# 📝 Lista de Tarefas

Aplicação web simples e funcional para gerenciar tarefas do dia a dia, desenvolvida com HTML, CSS e JavaScript puro.

## 🖥️ Demonstração

> Abra o arquivo `index.html` diretamente no navegador para usar a aplicação.

## ✨ Funcionalidades

- ➕ Adicionar novas tarefas
- ✅ Marcar tarefas como concluídas (e desfazer)
- ✏️ Editar tarefas existentes
- 🗑️ Remover tarefas individualmente
- 🧹 Limpar toda a lista de uma vez
- 💾 Dados salvos automaticamente no navegador (localStorage)
- ⌨️ Suporte a tecla Enter para adicionar tarefas
- 🕐 Data e hora de criação de cada tarefa

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage API

## 🚀 Como executar

1. Clone o repositório:
```bash
git clone https://github.com/kaug-bits/lista-de-tarefas
```
2. Abra o arquivo `index.html` no seu navegador.

Pronto! Nenhuma instalação necessária.
